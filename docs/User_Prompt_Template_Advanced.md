# Learning Experience Request (LER)

## 1. Learning Goal
What do you want to learn?

## 2. Target Audience
Who is this for?
(e.g., Beginner, Intermediate, Advanced, School Student, College Student, Professional)

## 3. Prior Knowledge
What do you already know about this topic?
(Optional)

## 4. Learning Objective
What should you be able to do after completing this learning experience?

## 5. Preferred Representation
How would you like the learning experience to be delivered?

Examples:
- Lesson
- Video Script
- Slide Deck
- Interactive Lesson
- Story
- Comic
- Manga
- Podcast
- Quiz
- Flashcards
- Blog
- Documentation
- Other

If unsure, write:
"Choose the most effective representation."

## 6. Preferred Learning Style
(Optional)

Examples:
- Visual
- Story-based
- Analogy-driven
- Hands-on
- Step-by-step
- Interactive
- Mixed

If unsure:
"Choose the most effective approach."

## 7. Scenario / Environment Preference
(Optional)

Examples:
- Everyday Life
- Space
- Robotics
- Business
- Mythology
- Fantasy
- Healthcare
- Sports
- Detective
- Historical
- Nature

Or

"Choose the best educational environment."

## 8. Constraints
(Optional)

Examples:
- 15 minutes
- Beginner friendly
- No mathematics
- Python examples
- Java examples
- Interview focused
- Exam focused

## 9. Output Requirements
(Optional)

Examples:
- Include practice questions
- Include exercises
- Include assessment
- Include diagrams
- Include code
- Include summary
- Include misconceptions

## 10. Additional Notes
(Optional)

Anything else you want CKLIS to know.
